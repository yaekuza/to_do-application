TakenHandelaar — current status
===============================

Core app
--------
- React/Vite frontend with auth, dashboard, weekly calendar, notes, profile stats,
  settings, and responsive layout rules.
- Frontend saves profile, tasks, and notes directly through Supabase
  with RLS, so local demos do not require the Go backend to be running.
- Go API with profile, categories, tasks, and notes handlers remains available
  as an optional backend layer.
- Supabase schema with RLS, signup profile trigger, notes migration, and
  expanded task statuses: open, in_progress, done.

Verified
--------
- Frontend production build passes:
  cd frontend && npm run build

Still needs local environment verification
------------------------------------------
- Backend build could not be run in this workspace because the Go toolchain is
  not installed here. On a machine with Go 1.22+, run:
  cd backend && go build ./...
- Full save testing requires configured Supabase frontend environment values
  and the SQL in supabase/full_setup.sql.

Setup reminders
---------------
- Backend needs DATABASE_URL, SUPABASE_JWT_SECRET, FRONTEND_ORIGIN, and optional
  PORT in backend/.env.
- Frontend needs VITE_SUPABASE_URL and VITE_SUPABASE_PUBLISHABLE_KEY in frontend/.env.
- OAuth callback in Google/Discord:
  https://<project-ref>.supabase.co/auth/v1/callback
- Supabase redirect URL:
  http://localhost:5173/auth/callback
