Notes for whoever picks this up
-------------------------------
- Stick to the design tokens in src/styles/tokens.css.
  Avoid box-shadow glows and gradient overlays — the user explicitly
  asked for a flat, soft, neon-purple-on-black look.
- The Go API path-value routing needs Go 1.22+ (uses
  mux.HandleFunc("GET /tasks/{id}", ...)).
- Supabase JWT is HS256 signed with SUPABASE_JWT_SECRET; the backend
  reads the "sub" claim as the user id and trusts it for all writes.
  RLS is on as a second line of defense.
- OAuth redirect URL to register in both Google Cloud and Discord:
  https://<project-ref>.supabase.co/auth/v1/callback
  Site URL in Supabase: http://localhost:5173
  Redirect URLs in Supabase: http://localhost:5173/auth/callback
