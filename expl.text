Project: TakenHandelaar (React.js + Go) 

Doel van het product Een full-stack webapplicatie waarmee je als student je eigen schooltaken kunt beheren: taken toevoegen met deadline en prioriteit, taken sorteren per vak, markeren als klaar en overzicht houden van wat nog moet gebeuren. React.js voor de frontend, Go voor de backend. 

Doelgroep Studenten (18-25 jaar) op mbo/hbo/universiteit die hun eigen taken willen organiseren.

Technisch ontwerp 

Frontend: React.js (Vite), component-based, fetch/axios naar API 

Backend: Go (net/http), JSON REST API 

Database: SQLite (via database/sql) Tabel users: id, email, password_hash Tabel tasks: id, user_id, title, description, deadline, category (vak), priority (hoog/midden/laag), status (open/done), date_created 

Functioneel ontwerp Use-cases

Gebruiker logt in (JWT) 

Gebruiker voegt nieuwe taak toe 

Gebruiker bekijkt taken (tabs: Te doen / Klaar / Per vak) 

Gebruiker bewerkt of verwijdert taak 

Gebruiker markeert taak als klaar
